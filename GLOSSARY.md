# Virgil Bakery

Sales site for the Virgil bakery. Broader domain vocabulary lives in `CONTEXT.md`; this glossary holds terms resolved after it.

## Language

**Greutate de livrare** (Shipping Weight):
A product's billable weight, recorded in whole grams — the authoritative number behind the GLS Home Delivery fee. Counted per unit ordered (a set's full weight applies to each set in the cart), and distinct from any display wording, such as the old free-text labels ("Pachet", "Set 5 buc").
_Avoid_: Free-text weight labels; "gramaj"
